# Aytor

Hola! necesito crear una landing page que hable sobre mi trabajo.

Basicamente que pase todo mi cv a una landing donde pueda explicar todo lo que hago, enfocado a growth marketing, estrategias multicanal y marketing de automatizaciones.

Aunque mi CV no habla mucho de eso, actualmente ofrezco servicios relacionados a automatizaciones de GoHighLevel mayormente, creo bots, hago setup automatizados y creo flujos de trabajos y de operaciones. Quiero enfocar mi perfil que domino todas las areas del marketing para crear estrategias efectivas para mis clientes.

Referencias de diseño:
quiero una paginas literalmente asi, me encantó este modelo https://digitalize.framer.media/ 
Mi linea gráfica usa tonos gris claros, gris oscuro y blanco, muy poca presencia de negros y puede haber uno que otro color neutro.
